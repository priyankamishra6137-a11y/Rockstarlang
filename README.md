# Rockstarlang (v0.3)

A Rockstar Games-inspired esoteric programming language and custom interpreter built from scratch in pure Python. Designed around GTA and RDR mechanics, mission blocks, and cheat-code syntax.

> **Note:** Built, tested, and maintained entirely on an Android mobile development workflow (**Termux + Acode**) without a PC setup.
